# Solutions

APCS-Practice v2 的新題目統一放在這裡。

**不用再依照資料結構 / 演算法類型選資料夾。** 分類由 metadata tags 自動完成。

建議命名：

```text
<problem-id>_<short-name>.cpp
<problem-id>_<short-name>.py
```

例如：

```text
b130_Random_Number.cpp
```

最小 metadata：

```cpp
// APCS Title: b130. 明明的隨機數
// APCS Complexity: O(N log N)
// APCS Tag: Sorting, Set
// APCS Difficulty: 1
```

完成後：

```powershell
python tools/apcs.py finish b130 2
```

完整流程見 [`docs/WORKFLOW.md`](../docs/WORKFLOW.md)。
