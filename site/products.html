我現在該買哪一種？

產品庫不是要讓使用者全部買，而是讓不同階段只有一個最自然的下一步。

剛開始 / 五項都不穩

先做免費診斷 → 7 日弱點重整 → P1 30 天核心訓練。

會寫，但常 WA / RE / TLE

直接進 P2 Debug Lab，不需要把整套基礎重學一次。

程式識讀 / 觀念題不穩

選 P3 Concept Sprint，集中練 code tracing、複雜度與資料結構判斷。

考期很近

剩 14 天左右直接用 P4 Sprint + Mock；不要臨時開一門 30 小時大課。
