Prefix / Greedy

Prefix Sum：
不要每次重算區間

若陣列不修改，但會有很多次區間總和詢問，
可以先建立：

prefix[0] = a[0];
for (int i = 1; i < n; ++i)
  prefix[i] = prefix[i-1] + a[i];

當 l > 0 時，區間 [l,r] 的總和是：

prefix[r] - prefix[l-1]

這把每次查詢從線性掃描降成常數時間。

最常見錯誤

直接寫 prefix[r] - prefix[l] 會少算 a[l]。
而 l=0 時，也要避免存取 prefix[-1]。
