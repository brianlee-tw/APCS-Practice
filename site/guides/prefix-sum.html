Prefix Sum：不要每次重算區間

當同一個陣列會被問很多次區間總和，先把累積資訊算好，就能把每次查詢從線性掃描降成常數時間。

閱讀時間4–5 分鐘
能力Implementation
核心概念Prefix Sum

先建立累積和

C++
prefix[0] = a[0];
for (int i = 1; i < n; ++i)
  prefix[i] = prefix[i-1] + a[i];

當 l > 0 時，區間 [l,r] 的總和是 prefix[r] - prefix[l-1]。這把每次區間查詢從 O(N) 降成 O(1)。

最常見的公式錯誤

直接寫 prefix[r] - prefix[l] 會少算 a[l]；而 l = 0 時也要避免讀取不存在的 prefix[-1]。

實作前檢查

  • 確認 prefix 的定義是「含自己」還是「前 i 個」。
  • 先用 3–5 個元素手算一次。
  • 特別測試 l = 0 與單一元素區間。
  • 確認資料型別能容納累積總和。
