Algorithm / Complexity

TLE 怎麼判斷：先看 Big-O

TLE 的第一個問題不是「要不要把 cin 換掉」，而是：目前方法會執行多少次核心操作？

for (int i = 0; i < n; ++i)
  for (int j = 0; j < n; ++j)
    work();

這個結構是 O(n²)。如果 n 很大，單純換快一點的輸入方式通常無法改變數量級。

快速檢查

  1. 先讀 constraints。
  2. 估算目前演算法的 Big-O。
  3. 找出最深層重複工作。
  4. 再考慮排序、二分、前綴和、資料結構或其他降低重複計算的方法。
  5. 最後才做常數級優化。
