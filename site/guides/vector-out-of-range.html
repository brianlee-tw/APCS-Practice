C++ vector 越界：先檢查 i < n

很多 RE 與「本機可以、評測壞掉」的問題，不是演算法太難，而是索引已經走到容器外面。

閱讀時間3–4 分鐘
能力Debug
常見錯誤off-by-one

先記住合法索引

若 vector 有 n 個元素，合法索引是 0 到 n-1。因此遍歷全部元素通常寫成：

C++
for (int i = 0; i < n; ++i) {
  cout << v[i] << '\n';
}
關鍵差別

i < n 的最後一次是 i = n-1；如果寫成 i <= n，最後會嘗試讀取不存在的 v[n]。

為什麼有時候不會立刻壞？

越界存取屬於未定義行為。程式可能 RE，也可能暫時印出看似合理的值，所以「我的電腦跑得動」不能證明程式正確。

除錯順序

  • 確認容器目前的 size。
  • 先寫出合法索引範圍。
  • 檢查迴圈終點是否誤用了等號。
  • 二維矩陣再檢查 row / column 是否顛倒。
