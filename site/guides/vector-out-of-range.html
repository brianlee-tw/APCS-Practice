C++ vector 越界：先檢查 i < n

若 vector 有 n 個元素，合法索引是 0 到 n-1。因此遍歷全部元素通常寫成：

for (int i = 0; i < n; ++i) {
  cout << v[i] << '\n';
}

把條件誤寫成 i <= n 時，最後一次會存取 v[n]。這超出合法範圍，屬於未定義行為；可能看似正常，也可能 RE，因此不能以「我的電腦沒壞」判定程式正確。

除錯順序

  1. 確認容器 size。
  2. 列出合法索引範圍。
  3. 檢查迴圈起點、終點與是否含等號。
  4. 再檢查二維矩陣的 R/C 是否顛倒。
