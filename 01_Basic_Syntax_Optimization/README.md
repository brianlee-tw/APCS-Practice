# 01_Basic_Syntax_Optimization: 語法特性與實作優化
本章節聚焦於 C++ 與 Python 的基礎語法高效應用，重點在於 I/O 優化與基礎邏輯的簡潔實現。

<br>

### 💡 學習策略
這些題目雖然基礎，但卻是所有高階算法的基石。重點在於觀察題目限制，並使用最適合的語法結構來降低時間複雜度。

<br>

### 關鍵術語
- `io`: 輸入輸出優化
- `cond`: 條件邏輯
- `loop`: 迴圈結構
- `func`: 函式封裝
