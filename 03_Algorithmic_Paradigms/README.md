# 03_Algorithmic_Paradigms: 核心演算法典範
本章節收錄了 APCS 考試中最核心的演算法思維，是提升解題效率與挑戰難題的關鍵。

<br>

### 💡 學習策略
重點在於「狀態轉移」與「規律挖掘」。透過暴力破解法 (Brute Force) 建立底層邏輯，並進一步轉換為貪心法 (Greedy) 或動態規劃 (DP) 的高效解法。

<br>

### 關鍵術語
- `bf`: 暴力破解
- `greedy`: 貪心演算法
- `sort`: 排序演算法
- `bs`: 二分搜尋
- `dp`: 動態規劃
