Reading Call Trace
多次 call 各自建立 local state；不要把上一個 call 的 locals 帶到下一次。

1｜題目與預測

Lab flow
先預測 → 操作/trace → 用一句話解釋結果。先想再點，不把 UI 當答案播放器。
int f(int x){ int y=x+1; return y; } cout << f(2) << ' ' << f(5);

2｜操作、觀察與解釋

call #1: x=2 → y=3 → return 3 → locals destroyed call #2: x=5 → y=6 → return 6 → locals destroyed
帶走的心智模型
每次 call 都有自己的 local state；上一個 call 的 local 已結束 lifetime，不會神祕延續到下一次。
