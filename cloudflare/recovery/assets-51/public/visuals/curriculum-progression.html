APCS Curriculum · Four-stage progression

四段式能力 progression

同一條主線從語言底座，經 3+3 Core 與 Bridge，最後進入 5+5 Core；Reading / Implementation 共用同一 curriculum。
01Units 01–02

Foundation

語言、控制、Array / Vector / String、2D data 與 Simulation。先做到可靠讀碼，並能從空白完成基礎程式。

Outcome · 基礎 R-M1 / I-M1
02Units 03–04

APCS 3+3 Core

Constraints、Complexity、Code Reasoning、Sorting 與 structured sequence data。Required Gates 完成後即可進 benchmark。

Checkpoint · RR3 + IR3
03Units 05–09

Bridge｜3+3 → 5+5

Prefix、Window、Binary Search、Recursion / Search、common DS。重點是從已知模型轉移到陌生情境。

Outcome · RR4 / IR4 transfer
04Units 10–12 + 14

APCS 5+5 Core

Graph / Tree、Greedy、DP、Mixed modeling / Mock。以陌生題建模、正確性與 mixed benchmark 收斂。

Readiness · RR5 / IR5
Advanced Calibration：U-RNG（Unit 13）保留 Supporting + Extension depth，但不作 universal 5+5 blocker；S25–S28 與 S36 亦不因未完成而阻擋 readiness。
